# Brandschutz Formular – Android Version 1

Dieses Projekt ist für Android Studio vorbereitet.

## Funktionen
- Frage-für-Frage Eingabe
- Auswahlfelder passend zum bereitgestellten Formular
- Kameraaufnahme / Foto wiederholen
- Original-PDF als Vorlage
- Foto oben links im freien Bereich
- Erste Stammdaten werden in das PDF geschrieben
- PDF wird im App-Dokumentenordner gespeichert

## Öffnen
Projektordner `AndroidBrandschutz` in Android Studio öffnen und auf einem Android-Gerät/Emulator starten.

Hinweis: Für Version 1 sind die PDF-Koordinaten bewusst als erste Arbeitsversion gesetzt. Die übrigen Felder können in Version 2 exakt auf die Formularlinien gelegt werden.
